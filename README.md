# 붕괴: 스타레일 뉴비 가이드북

뉴비를 위한 **실전 중심** 스타레일 가이드북입니다.

## 목표
- 완전 초보자가 게임을 시작하고 1~2주 안에 적응할 수 있도록 정리
- 맵 파밍, 행동 게이지, 비술, 팀 구성, 유물 세팅까지 실전적으로 설명
- 캐릭터 추천 + 초보자용 추천 파티 제공

## 현재 상태
- 단일 HTML 파일로 제작 (GitHub Pages에 바로 배포 가능)
- 검색 + 카테고리 필터 지원
- 모달로 상세 가이드 확인 가능

## 배포 방법 (GitHub Pages)

1. GitHub에 새 저장소 만들기 (이름 추천: `starrail-guide`)
2. 이 폴더 안의 모든 파일을 저장소에 업로드
3. 저장소 설정 → Pages → Source를 `main` 브랜치 + `/ (root)` 선택
4. 저장소 주소가 `https://너의아이디.github.io/starrail-guide/` 로 생성됨

## 폴더 구조 (추후 확장 시)

```
starrail-guide/
├── index.html          # 메인 가이드북 (현재)
├── images/             # 가이드 스크린샷 모음
├── guides/             # (추후) 개별 가이드 파일 분리용
└── README.md
```

## 가이드 추가 / 수정하는 법 (가장 중요!)

**왜 `guides-data.js`만 만지라고 하나요?**

- `guides-data.js` = 가이드 **내용**만 들어있는 파일 (이것만 수정하세요)
- `index.html` = 사이트 전체를 만드는 **코드**가 들어있는 파일 (이건 거의 건드리지 마세요)

`index.html`을 잘못 고치면 사이트가 아예 안 열릴 수 있기 때문에, 가이드 추가/수정은 `guides-data.js`에서만 하도록 분리했습니다.

자세한 방법은 같은 폴더 안에 있는 **`HOW_TO_EDIT.md`** 파일을 열어서 읽어보세요. 초보자도 따라할 수 있게 자세히 설명되어 있습니다.
